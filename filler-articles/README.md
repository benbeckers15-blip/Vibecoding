# Filler Articles

These screens and data were part of the home screen's "Explore By" feature.
They are preserved here but are NOT routed or visible in the app.

To restore them, move the files back into `app/(tabs)/home/articles/` and
re-add the `EXPLORE_TILES` constant + "Explore By" section to `app/(tabs)/home/index.tsx`.

## Contents
- `collections/[key].tsx` — dynamic collection screen (winery filter by boolean tag)
- `behind-the-cellar-door.tsx`
- `hidden-gems.tsx`
- `pairings.tsx`
- `sommelier-recommendations.tsx`
